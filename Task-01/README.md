# Task 01 - Video Game Sales Analysis

An exploratory analysis of historical video game sales data completed for the Devixo Solutions AI/ML Internship Program.

## Contents

- `dataset/vgsales.csv` - Video game sales dataset.
- `notebook/Task_01_Data_Analysis.ipynb` - Data cleaning, exploratory analysis, statistical analysis, and visualizations.
- `report/Task_01_Report.pdf` - Task report.
- `images/` - Exported analysis images.

## Analysis Areas

- Dataset inspection and cleaning
- Global and regional sales comparison
- Platform, genre, and publisher performance
- Time-based release trends
- Correlation and statistical summaries

## Run the Notebook

From the `Task-01/notebook` directory, open `Task_01_Data_Analysis.ipynb` in Jupyter or VS Code. The notebook expects the dataset at `../dataset/vgsales.csv`.

Install the Python dependencies with:

```bash
pip install pandas numpy matplotlib seaborn
```
